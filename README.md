# AudR — Голосовые заметки

Простое учебное Android-приложение для работы с голосовыми заметками (запись, импорт из хранилища устройства, проигрывание, удаление, переименование).

## Возможности

### Запись
- Запись аудио с микрофона (M4A/AAC, 128 kbps, 44100 Гц);
- Таймер записи;
- Возможность задать название аудио после остановки записи;
- Автоматическое задание имени аудио: «Запись от DD.MM.YYYY HH:MM:SS».

### Импорт
- Импорт аудиофайлов из памяти устройства;
- Поддерживаемые форматы: MP3, WAV, OGG, AAC, M4A;
- Множественный выбор файлов;
- Лимит размера: 100 МБ на файл;
- Автоматическое извлечение длительности.

### Проигрывание записей
- Воспроизведение / пауза;
- Перемотка ±10 секунд;
- Прогресс-бар с перемоткой;
- Отображение текущего времени и общей длительности.

### Список записей
- Отображение названия, длительности, даты;
- Иконки статуса (запись / импорт);
- Поиск по названию;
- Сортировка:
  - Дата (новые / старые);
  - Название (А→Я / Я→А);
  - Длительность (короткие / длинные).
- Фильтры:
  - Все записи;
  - С микрофона;
  - Импортированные;
  - Избранные.

### Действия с записями
- Добавить / убрать из избранного;
- Переименовать запись;
- Множественный выбор записей (долгое нажатие);
- Удаление записи с подтверждением;
- Удаление нескольких записей с подтверждением.

### Интерфейс
- Тёмная / светлая тема;
- Material Design 3;
- Jetpack Compose;
- Snackbar-уведомления (пустое название, удаление);
- Обработка системной кнопки «Назад».

## Сборка и запуск приложения

1. Клонируйте репозиторий:
```
git clone https://github.com/Vasya07/Project_AudR.git
```
2. Откройте проект в Android Studio
3. Соберите проект:
```
./gradlew assembleDebug
```
4. Запустите приложение на эмуляторе или своем устройстве

## Структура проекта
